# LXIUM_sample

LXIUM 게임 모드(애드온) 프로젝트 템플릿입니다.
새 게임 모드는 이 저장소를 복사해 `LXIUM_<게임 id>` 저장소로 만듭니다. 사용법은 [AGENTS.md](AGENTS.md) 맨 위 주석에 있습니다.

| 파일 | 내용 |
|---|---|
| `lxium.json` | 애드온 정보 템플릿 |
| `LXIUM_sample.lxconfig` | 설정 설명(다국어) 예시 → [설정 안내](docs/human/config.md) |
| `docs/human/game.md`, `docs/ai/game.md` | 게임 분석 문서 틀 |
| `docs/human/config.md`, `docs/ai/config.md` | 설정·`.lxconfig` 쓰는 법 |

- 런처·애드온 규격: https://github.com/LocalXtend/LXIUM
